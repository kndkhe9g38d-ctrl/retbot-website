# RET Public Website V100

A real static/public RET website built for GitHub Pages.

## What V100 includes
- RET supplied logo as the visual identity
- Responsive futuristic purple design
- Animated hero and reveal effects
- Public bot invite + support links
- Feature ecosystem section
- Searchable/filterable public command showcase
- Developer section
- Mobile navigation
- SEO/OpenGraph metadata
- No secret token required for the static website

## GitHub Pages
Upload all files to the repository root and enable GitHub Pages from Settings > Pages > Deploy from branch.

## Important
Do NOT put a Discord bot token, client secret, or other private credential in HTML, CSS, JavaScript, or a public GitHub repository.
A live dashboard/login/status API needs a server-side backend; GitHub Pages alone is static hosting.
